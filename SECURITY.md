# Security Policy

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitLab issues.

Vulnerabilities can be reported via general Eclipse Foundation means: an [email to security@eclipse-foundation.org](security@eclipse-foundation.org) or an issue in the [general vulnerability issue tracker](https://gitlab.eclipse.org/security/vulnerability-reports/-/issues/new?issuable_template=new_vulnerability).

See [Eclipse Foundation Vulnerability Reporting Policy](https://www.eclipse.org/projects/handbook/#vulnerability).
